# Campus fonts

Manrope and Fraunces roman variable fonts are bundled from the official Google Fonts repository at commit `86aced91de05cd4f96a06838124cca45be337b2b`. Each family retains its SIL Open Font License 1.1 in the adjacent `*-OFL.txt` file.

- Manrope: https://github.com/google/fonts/tree/86aced91de05cd4f96a06838124cca45be337b2b/ofl/manrope
- Fraunces: https://github.com/google/fonts/tree/86aced91de05cd4f96a06838124cca45be337b2b/ofl/fraunces

The complete fonts include Latin Extended glyphs for Turkish. They are served locally with preload disabled; public/auth/system surfaces keep IBM Plex Sans. No build-time or runtime Google Fonts request is made.
